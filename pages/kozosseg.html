Beszélgetések

ℹ Hogyan működik? A kommentek a GitHub Discussions rendszerében tárolódnak. Kattints a "Bejelentkezés GitHub-bal" gombra — ingyenes GitHub-fiókkal is használható. Az adataid nem kerülnek hozzánk.
🛠 Beállítási segédlet a GitHub Discussions integrációhoz:
  1. GitHub-on hozz létre egy tm3-hu/tm3-hu.github.io repót (vagy sajátot).
  2. Engedélyezd a Discussions funkciót a repo Settings → Features alatt.
  3. Telepítsd a giscus.app alkalmazást a repóra.
  4. Másold ki a repo-ID-t és category-ID-t, és frissítsd a fenti script tag-eket.
